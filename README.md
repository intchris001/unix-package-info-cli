# Unix Package Information CLI

A Python command-line utility for reading a CSV package index and printing installed package names, total package size, or details for a named package.

## Usage

```bash
python3 pkginfo.py -a packages.csv
python3 pkginfo.py -s packages.csv
python3 pkginfo.py -l git packages.csv
python3 pkginfo.py -v packages.csv
```

The repository uses generic sample package data. No student identifiers or course handouts are included.
